# Code of Conduct

## The short version

Be decent. Argue about the work, not the person. Assume the other side is
acting in good faith until they clearly are not.

## Expected behaviour

- Keep technical disagreement technical. "This benchmark does not measure what
  the README claims" is welcome. Personal attacks are not.
- Accept that a maintainer may decline a change. Scope is a real constraint.
- Respect the biosecurity boundaries in `SECURITY.md`. Requests to remove the
  manifest gate or the exclusion list will be closed.

## Unacceptable behaviour

Harassment, discriminatory language, sustained disruption, publishing private
information, and any attempt to use this project's issue tracker to coordinate
work on select agents or toxins.

## Enforcement

Reports go to the maintainer through GitHub (open a private security advisory
if the report itself is sensitive). The maintainer may edit, close, or block
without further discussion. There is no committee here; a single person reads
these, and will try to be fair about it.

This is adapted in spirit from the Contributor Covenant, condensed to what one
maintainer can actually enforce.
